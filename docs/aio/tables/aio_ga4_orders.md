# All In One - transaction data from Google Analytics 4

## Purpose and Main Use Cases 🎯

The table aio_ga_orders is used for **analyzing e-commerce transactions recorded by Google Analytics 4**. It is an alternative view of sales data compared to aio_ecommerce_orders, which is based on data directly from store systems (backend). This datamart is particularly useful when you want to analyze sales from the perspective of analytics data, which contains the full context of sessions and traffic sources.

Similar to other datamarts, aio_ga_orders also includes **aggregated marketing costs**, allowing you to calculate profitability metrics (e.g., **ROAS**) for transactions tracked by GA4 and attributed to specific sessions.

## Included Source Systems 🔌

This table combines data from two main categories:

- **Transaction Data (User Behaviour):**
    - **Google Analytics 4 BigQuery:** Order-level data (Google Analytics 4 BigQuery - Orders - GA4).
- **Marketing Cost Data (Ad Systems):**
    - Awin, Bing Ads, Ceneo, Convertiser, Criteo Ads, Domodi & Allani, Facebook Ads, Google Ads, Optimise, RTB House, TikTok, Tradedoubler.

## Table Location in BigQuery 📍

The table is located in BigQuery at the path:
`witcloud_{project-id}.aio_ga_orders`

## Data Structure and Granularity 🧱

1. **A single transaction (order)** recorded by Google Analytics 4.
2. **Aggregated daily marketing cost** from a given advertising system.

This architecture allows for easy comparison of GA4 transaction revenue with the costs incurred for marketing in the same periods.

**Key groups of fields:**

- **Data Source Dimensions:** data_source_type, data_source_name, etc.
- **GA4 Transaction Dimensions:** ga_transaction_id, ga_session_source, ga_session_medium, etc.
- **GA4 Transaction Metrics:** ga_totals_revenue, ga_shipping_revenue_inc_tax, etc.
- **Marketing Dimensions and Metrics:** ad_system_campaign_name, ad_system_cost, ad_system_clicks.

## Typical Analytical Questions this table answers 🤔

- What revenue from GA4 transactions was generated by google / cpc campaigns compared to their cost?
- How many transactions were attributed to sessions from organic entries (organic) last month?
- What is the ROAS for Facebook campaigns, based on revenue tracked by GA4?
- Which traffic sources generate transactions with the highest average value?

## Important Notes and Limitations ⚠️

- **Key rule for date filtering:** The table is partitioned. To keep your queries fast and inexpensive, **always filter data using the \_PARTITIONTIME pseudo-column**.
- **Two types of rows:** Remember that this table contains two kinds of data. Rows with marketing data (data_source_type = 'Ad Systems') will not include GA4 transaction details (e.g., ga_transaction_id will be NULL), and vice versa.
- **Source of transaction data:** The data in this table comes from analytics (frontend), not directly from your store system (backend). Discrepancies compared to the data in the aio_ecommerce_orders table may occur due to, for example, ad blockers, differences in attribution, or untracked transactions.

## Example SQL Queries

### Comparison of GA4 transaction revenue with marketing costs on a daily basis

```sql
SELECT
  date,
  SUM(ga_totals_revenue) AS ga_revenue,
  SUM(ad_system_cost)    AS total_cost,
  SAFE_DIVIDE(SUM(ga_totals_revenue), SUM(ad_system_cost)) AS roas
FROM
  `witcloud_{project-id}.aio_ga_orders`
WHERE
  _PARTITIONTIME >= TIMESTAMP(DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY))
GROUP BY
  date
ORDER BY
  date DESC;
```

### Number of transactions and revenue by channels (source/medium) in the current month

```sql
SELECT
  ga_session_source,
  ga_session_medium,
  COUNT(DISTINCT ga_transaction_id) AS number_of_transactions,
  SUM(ga_totals_revenue) AS total_revenue
FROM
  `witcloud_{project-id}.aio_ga_orders`
WHERE
  _PARTITIONTIME >= TIMESTAMP(DATE_TRUNC(CURRENT_DATE(), MONTH))
  AND ga_transaction_id IS NOT NULL
GROUP BY
  ga_session_source,
  ga_session_medium
ORDER BY
  total_revenue DESC;
```
